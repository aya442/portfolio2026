LiveFx

スマートフォンをペンライトのように使い、ライブをより盛り上げるチーム開発プロジェクト。

15人規模のプロジェクトに2期生として参加。担当した画面では、桜をスワイプすると桜の木に反映されるインタラクションを実装しました。 また、会議の進め方を見直して所要時間を3時間から1時間に短縮。完成したシステムは、グループ校の入学者約4,000人を前に実演し、正常に動作しました。

React / TypeScript / Vite / Express / WebSocket / Docker
ソースコード（GitHub） 紹介サイト（操作にはコントロールPCが必要）

FE QUIZ

一人では続けにくい基本情報技術者試験の勉強を、友人やクラスメイトとの対戦で続けやすくするクイズアプリ。

Firebaseを使ったリアルタイム対戦機能を担当しました。ルーム作成で参加人数に上限を設け、友人と合流しやすくしました。 制作を通じて、よいアイデアを使いやすいアプリにするには、機能を整理して組み合わせることが大切だと学びました。

HTML / React / Node.js / Vite / Firebase

公開デモあり

zatu-TODO

メモ帳のような気軽さと、「今日やること」に集中できるシンプルさを組み合わせたTODOアプリ。

個人で企画し、実装にはAIを活用しました。1行入力でのタスク追加、日付の自動判定、ドラッグ＆ドロップでの移動、複数端末でのデータ同期を制作。 友人からはタスクをドラッグして日程変更できる機能が好評でした。今後はUIを改善したいと考えています。

React / Vite / Firebase Authentication / Firestore / CSS

デモURLは非掲載（ログイン後にデータを扱うため）
