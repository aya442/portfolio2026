zatu-TODO

タスク管理ツール自体の作成にかかる手間を削減するアプリ。

1行でタスクを入力するだけで追加でき、日付の自動判定やドラッグ操作でのタスク移動が可能。Firebase Authentication と Firestore を使用して複数端末でのデータ同期とダークテーマ対応を実装しました。

React 19 / Vite 8 / Firebase (Authentication + Firestore) / CSS / ESLint
GitHub

NapNap

生活習慣を変えたいと思いながらも、行動に移すことができない人のための睡眠サポートアプリ。

ユーザーの睡眠習慣改善を支援するモバイルアプリのUI/UXデザイン。行動変容を促すための直感的なインターフェースとユーザーフレンドリーな操作性を重視し、プロトタイプを設計しました。

UI / UX Design / Figma
idea Prototype

LiveFx

ライブパフォーマンス向けの双方向インタラクティブシステム。

コントロールPCからの操作をスマートフォンへリアルタイムに届け、ライブ演出を複数の画面で同期させるチーム開発プロジェクトです。 フロントエンドの実装を担当し、WebSocketを使ったリアルタイム通信やReactによる画面づくりに取り組みました。

React / TypeScript / Vite / Express / WebSocket / Docker
