# ポートフォリオ

就職活動向けに、制作実績・使用技術・プロフィールを紹介する静的なポートフォリオサイトです。

**公開サイト:** https://aya442.github.io/portfolio2026/

## 掲載内容

- **Projects:** LiveFx、FE QUIZ、zatu-TODO、NapNap
- **About:** 学歴、キャリア目標、資格、経験
- **Skills:** 制作物や授業での技術使用例
- **デッサン:** 観察・表現を学んだ作品
- **Contact:** メールとGitHubプロフィール

## 技術

- HTML
- CSS
- JavaScript Canvas（星空のアニメーション）

ビルドツールやパッケージのインストールは不要です。ローカルで確認する場合は、`index.html`をブラウザーで開いてください。

## 主なファイル

- `index.html` — ページ構造と掲載内容
- `style.css` — レイアウト、配色、レスポンシブスタイル
- `stars.js` — 星空と流れ星のアニメーション
- `project_img/` — 制作実績の画像
- `picture_img/` — デッサン作品の画像
